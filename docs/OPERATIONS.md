# 室戸沖システムの運用方針（2026-10-07）

## 入口

- `ocean/index.html`：海流情報と出船判断。船選択は不要。
- `catch/index.html`：既存の釣果DB・解析DBを閲覧。船フィルタは従来どおり。
- ルートの `index.html` は海流・出船判断の入口。
- 旧 `viewer.html` は釣果入口へ転送し、船フィルタのクエリを引き継ぐ。

## 継続する自動処理

- `update_data.yml`：前日の海流・水温・塩分を取得し、CSVと表示用JSを更新。
- `update-forecast.yml`：出船判断用の最新予報を取得し、JSONを更新。
- `rebuild_master.yml`：既存の週次整合性検査。生成先は一時領域で、保存済み釣果データは書き換えない。
- GitHub Pagesの公開処理。

## 停止する処理

以下のジョブを `if: ${{ false }}` で停止。定義と既存データは保持する。

- `ingest_dropins.yml`：新規釣果の取り込み。
- `sync_after_master_push.yml`：釣果更新に伴う気象差分取得・派生CSV・解析再生成。
- `sync_after_current_update.yml`：海流更新後の気象・釣果解析再生成。

釣果は蓄積済みの記録を閲覧するアーカイブとして運用する。CSV、JSON、画像、解析の数値内容をこの変更では改変しない。
海流・予報の取得条件、地点、判断基準、スケジュールは維持する。
過去の欠損日や海流の座標変更は、今回の入口分離では補正しない。

再開時は上記3ジョブの停止条件と入口の表記を見直す。海流・予報の自動更新はGitHub Actionsの実行履歴と各画面の日付で確認する。
